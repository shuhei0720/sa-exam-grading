# 専門分野・現場業務との整合性

基準版：v0.2。2026-11-10のユーザー指定で追加した観点。書籍からの引用やIPAの独立配点ではない。

## 判定の目的

薬剤師・薬局など専門分野を題材とする答案について、現場の実際の業務との矛盾、事実と異なる記述、専門家が読んだときに生じる違和感を確認する。医療以外の金融・物流・製造等にも同じ方法を適用する。

## 調べる範囲

| ID | 観点 | 確認内容 |
| --- | --- | --- |
| D01 | 役割と権限 | 誰が依頼・判断・承認・実行するか。職種や組織の役割を混同していないか |
| D02 | 業務の順序 | 入力、照会、確認、実行、記録の順序と前提が自然か。異なる工程を同時実施するように書いていないか |
| D03 | 用語・情報 | 専門用語、製品固有語、データの意味を正確に使い、非専門家にも必要な説明があるか |
| D04 | 安全・品質上の確認 | 効率化により必要な確認を省略していないか。経験・記憶だけを根拠に確認不要としていないか |
| D05 | システムと運用 | 機器・データ連携・アクセス・可用性・情報管理と現場の運用条件が整合するか |
| D06 | 例外・誤操作 | 誤操作、未完了、変更、障害、例外を考えた設計か。問題の主題に関係する範囲で確認する |
| D07 | 施設・時期による差 | 院内／院外、入院／外来、診療科、施設規模、季節等を区別し、特定事例を一般化していないか |

## 判定を分ける

1. **確認できた矛盾・事実誤認**：答案の引用、比較先、成立条件を示す。内部矛盾と外部事実との矛盾も区別する。
2. **説明不足・誤読の恐れ**：実態は成立し得るが本文では判断できない。違法・危険な実施をしたと断定しない。
3. **施設固有・時点依存・未確認**：施設の運用資料、対象年度、本人の説明が必要。未確認だけで誤りとしない。
4. **設計改善の提案**：よりよい方法の候補であり、必須要件や実施済み事実と混同しない。

## 根拠の扱い

- 医療・法制度・安全などの事実確認は、行政資料、職能団体の指針、施設自身が公開する業務説明などの一次資料を優先する。
- URL、資料名、版・発行時点、確認日、該当箇所と適用範囲を記録する。
- 一病院の事例を全病院の共通ルールにしない。新しい指針で過去の事例を遡及して違反認定しない。
- 業務上の実績、患者数、アンケート人数、処理時間などを創作しない。
- 不足する事実は「要確認」とし、設問に関係しない細かな専門知識の網羅を要求しない。
- 臨床上の処方判断や患者への治療助言は、この論述添削の目的に含めない。

## 配点への反映

G06として横断確認する。元のR01～R10、合計100点は維持する。

| 影響 | 主に反映する項目 |
| --- | --- |
| 業務・役割の理解が不正確 | R01、必要に応じR03 |
| 前後の業務条件や手順が矛盾 | R05 |
| 採用理由が現場条件・根拠に合わない | R08 |
| 用語の意味が読者に伝わらない | R09 |

複数項目に影響するときは別々の影響を説明する。専門分野確認の結果を理由とする追加の一律減点はしない。重大な業務矛盾がある場合は総点と別に示す。
