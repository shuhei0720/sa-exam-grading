# 書籍掲載のIPA評価項目との対応

出典：BOOK-01 pp.55–56（図表2-6、2-7、2-8）。

この文書は提供書籍の記載を整理したものです。最新のIPA公式資料は未照合です。図表2-8の対応関係は、書籍著者による推測・整理として示されています。

## 書籍掲載の評価ランク

| ランク | 書籍掲載の趣旨 | 合否 |
| --- | --- | --- |
| A | 合格水準に到達している | 合格 |
| B | 合格水準まであと一歩である | 不合格 |
| C | 内容の不足、または問題文の趣旨からの逸脱がある | 不合格 |
| D | 内容の著しい不足、または出題要求からの著しい逸脱がある | 不合格 |

これらの区分と、書籍の100点方式を混同しない。特にC・Dの数値境界は提供ページから確認できない。

## 評価項目と書籍側の観点

| 書籍に掲載されたIPAの評価項目 | 書籍が対応付ける観点 | 採点で確認すること |
| --- | --- | --- |
| 設問で要求した項目の充足度 | 出題意図に応える記述内容 | 設問に従って構成し、必要な要素に回答している |
| 論述の具体性 | 分かりやすさのうち具体性 | 本人の経験、創意工夫、結果が明確 |
| 内容の妥当性 | 出題意図に応える記述内容 | 問題文に沿い、題意に合った内容 |
| 論理の一貫性 | 面白さのうち論旨展開の一貫性 | 導入から最後の設問まで一貫 |
| 見識に基づく主張 | 面白さのうち主張性 | 試験区分にふさわしい視点と、上級技術者としての実務能力 |
| 洞察力・行動力 | 面白さのうち主張性 | 同上。課題の理解と、本人の判断・行動が分かる |
| 独創性・先見性 | 面白さのうち主張性 | 同上。課題に応じた工夫と見通しが分かる |
| 表現力・文章作成能力 | 客観性、一般性、読みやすさ | 事実と意見の区別、一般的な用語、正しい表記 |

上記に加えて「解答に当たっての指示の遵守」が示されている（p.55）。

## 注意

書籍p.50には採点の定量化や複数採点者についての推測・伝聞が含まれる。これらを公式に確認された運用として扱わない。本リポジトリは評価項目と学習用の採点例を参照する。
