システムアーキテクト試験の論述答案を、書籍由来の基準と答案中の根拠に基づいて採点・添削するためのリポジトリです。

## 現在の対象

- 対象：提供書籍で扱われている午後IIの論述。
- 資料：2026年11月10日受領の写真11枚（pp.50–56、119–131、計20ページ）。
- 基準版：v0.2.1。
- 書名・著者・版・発行年：未確認。資料IDを `BOOK-01` として管理。
- 書籍の評価表：10項目×10点＝100点。実例は書き直し前53点、書き直し後71点。
- この採点は学習用の模擬評価です。書籍の配点をIPAの非公開の採点方法として扱いません。

## 採点の頼み方

このリポジトリを指定して、問題文・設問・答案を送ってください。質問書や所要時間があれば併せて確認します。質問書がない場合は、その整合性を未確認と記録します。

採点は「設問への回答状況 → 重大な不足 → 10項目の点数と根拠 → 設問別の修正案」の順で行います。点数だけで合格相当と判断せず、出題要求への適合と完結性も確認します。

答案・採点記録の保存先は、それぞれ [submissions](submissions/README.md)、[reviews](reviews/README.md) です。現在は基準のみを登録しています。

## 出典の扱い

公開リポジトリには、提供画像から整理した採点用の要約とページ参照を置いています。書籍の写真と例文全文は掲載していません。個別事例の数値・字数目安を、他の問題に一律適用しません。
